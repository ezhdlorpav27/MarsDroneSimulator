# MarsDroneSimulator
Чёрно-белая 2D-головоломка про строительство марсианской базы. Игрок управляет дроном и марсоходом, переносит грузы, открывает шлюзы и проходит через порталы, которые инвертируют цвета мира.

Особенности

Дрон: летает в условиях слабой гравитации и поднимает лёгкие грузы магнитным лучом.
Марсоход: возит тяжёлые контейнеры на тележке, грузит и выгружает их манипулятором, проезжает через порталы.
Порталы: переносят объекты с сохранением импульса и переключают мир между нормальным и инвертированным состоянием.
Элементы головоломок: кнопки и плиты (в том числе тяжёлые), раздвижные шлюзы, пылевые бури, не пускающие дрон, и фазовые стены, проницаемые только в инвертированном мире.
Уровни: 7 уровней с постепенным усложнением и меню выбора. Прогресс сохраняется в браузере.
Оформление: марсианская тематика, частицы, синтезированные звуковые эффекты, анимированное главное меню.
Управление: клавиатура (WASD / стрелки, пробел, E) и сенсорное управление для мобильных устройств.

Технологии
Чистые HTML, CSS и JavaScript с отрисовкой на Canvas 2D. Без сборки и зависимостей: достаточно открыть один .html файл в браузере.

Запуск
Откройте mars-drone-simulator.html в любом современном браузере.
